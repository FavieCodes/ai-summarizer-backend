📡 API Endpoints

POST /api/summarize/

Summarize webpage content using AI

GET /api/health/

Check API health and provider availability

📤 Request Format (Summarize)

{
  "title": "Page Title",
  "content": "Extracted page content (max 8000 chars)",
  "url": "https://example.com/page"  // optional
}

📥 Response Format

{
  "success": true,
  "summary": {
    "summary": ["bullet 1", "bullet 2", ...],
    "keyInsights": ["insight 1", "insight 2", ...],
    "readingTime": "X min read"
  },
  "provider": "groq",
  "fromCache": false
}

🐍 Python Example

                
import requests

url = "http://127.0.0.1:8000/api/summarize/"
data = {
    "title": "Article Title",
    "content": "Your article content here..."
}

response = requests.post(url, json=data)
print(response.json())
